原因：用 file:// 直接打开时，浏览器不允许页面读取 glyfs/jseshGlyphs/*.svg（同源策略）。

两种解法（任选其一）：

① 起一个本地服务：在仓库根目录执行 python -m http.server 8000，然后访问 http://127.0.0.1:8000/tks.html。

② 或者直接选择已解压的 SVG 目录：本页会通过 File System Access API 读取 glyfs/jseshGlyphs。
